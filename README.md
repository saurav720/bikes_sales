# 🚴 Bike Sales Data Analytics Project

## 📌 Project Overview
This project focuses on analyzing bike sales data to identify sales trends, customer behavior, top-performing brands, and overall business performance.  
The dashboard helps businesses make data-driven decisions by providing clear insights into revenue, profit, and sales performance.

---

# 🎯 Objectives
- Analyze bike sales performance
- Identify top-selling bike brands and models
- Track yearly and monthly sales trends
- Monitor profit and revenue growth
- Understand customer purchasing behavior
- Create interactive dashboards for better visualization

---

# 🛠️ Tools & Technologies Used
- Microsoft Excel
- Power BI
- SQL
- Data Cleaning & Transformation
- Data Visualization

---

# 📂 Dataset Information
The dataset contains information related to:
- Bike Brand
- Model Name
- Sales Amount
- Revenue
- Profit
- Units Sold
- Customer Details
- Region/City
- Date/Year of Sales
